HTML Basics

HTML (HyperText Markup Language) is the backbone of web pages.

It describes the structure of a web page semantically.

HTML elements are represented by tags like <h1> or <p>.

Each tag serves a specific purpose, such as defining headings, paragraphs, lists, etc.

HTML documents are read and rendered by browsers.

  • Headings: <h1> to <h6>
  • Paragraphs: <p>
  • Lists: <ul> or <ol>
  • Links: <a>
  • Images: <img>
CSS Fundamentals

CSS (Cascading Style Sheets) controls the presentation of web pages.

It allows you to style HTML elements with colors, layouts, and fonts.

You can apply styles inline, internally, or externally using stylesheets.

CSS uses selectors to target HTML elements.

It supports responsive design via media queries.

  • color: Sets the text color
  • font-size: Sets the font size
  • margin and padding: Control spacing
  • display: Defines layout behavior
  • flex: Enables flexible box layout
JavaScript Introduction

JavaScript adds interactivity and dynamic behavior to web pages.

It can manipulate the DOM, respond to user events, and communicate with servers.

JavaScript runs in the browser without needing a server.

It is one of the core technologies of the web alongside HTML and CSS.

Modern JavaScript uses ES6+ features like let, const, and arrow functions.

  • Variables: let x = 10;
  • Functions: function greet() {}
  • Events: element.addEventListener()
  • DOM Access: document.getElementById()
  • APIs: fetch() for HTTP requests
Responsive Design

Responsive design ensures websites work well on all screen sizes.

It uses flexible layouts, images, and media queries.

Mobile-first design starts with styling for small screens first.

Media queries apply different styles based on device characteristics.

Tools like Flexbox and Grid help build responsive layouts.

  • @media: Media query syntax
  • max-width and min-width: Set breakpoints
  • flex-direction: Layout flow in Flexbox
  • grid-template-columns: Grid layout columns
  • viewport: Defined in the HTML meta tag
Debugging Tips

Debugging is essential for finding and fixing code issues.

Use browser dev tools to inspect elements and view console logs.

console.log() is useful for tracking variable values.

Breakpoints help pause code execution in dev tools.

Linting tools like ESLint can catch errors early.

  • Console tab: Shows output and errors
  • Elements tab: Inspect HTML structure
  • Sources tab: Set breakpoints in JS files
  • Network tab: Monitor HTTP requests
  • Performance tab: Analyze load time
